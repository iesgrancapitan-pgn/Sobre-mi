## Formatos que debes usar
- Títulos y subtítulos (`#`, `##`)
- Listas simples y anidadas (`-`, `  -`)
- Imágenes (`![Texto alternativo](URL)`)
- Enlaces (`[Texto](URL)`)
- Negrita (`**texto**`)
- Cursiva (`*texto*`)
- Citas (`> texto`)

---

## Recomendaciones
- Personaliza el contenido con tus datos reales.
- Usa una foto tuya (puedes subirla al repositorio y enlazarla).
- Sé creativo y cuida la presentación.
