# Tarea: Mi Primer Repositorio Personal

## 📝 Descripción de la Tarea

Esta tarea está diseñada para que los estudiantes creen su primer repositorio de GitHub y aprendan a utilizar Markdown para presentar información personal de manera profesional.

## 🎯 Objetivos de Aprendizaje

Al completar esta tarea, los estudiantes serán capaces de:

1. **Crear y configurar un repositorio de GitHub**
2. **Escribir documentación en formato Markdown**
3. **Gestionar archivos en un repositorio Git**
4. **Presentar información personal de manera profesional**
5. **Utilizar las características básicas de Git (add, commit, push)**

## 📋 Instrucciones

### Paso 1: Crear tu Repositorio
1. Ve a [GitHub.com](https://github.com) e inicia sesión
2. Haz clic en el botón "New" o "Nuevo repositorio"
3. Nombra tu repositorio: `mi-primer-repositorio` o `sobre-mi`
4. Agrega una descripción: "Mi repositorio personal con información sobre mí"
5. Marca la casilla "Add a README file"
6. Haz clic en "Create repository"

### Paso 2: Estructura del Repositorio
Tu repositorio debe contener los siguientes archivos:

```
tu-repositorio/
├── README.md           # Archivo principal con tu información
├── intereses.md        # Tus hobbies e intereses
├── proyectos.md        # Proyectos actuales y futuros
└── contacto.md         # Información de contacto
```

### Paso 3: Completar los Archivos

#### 📄 README.md (Archivo Principal)
Este archivo debe contener:
- Tu nombre completo
- Una foto tuya (opcional)
- Una breve descripción personal (2-3 párrafos)
- Tu formación académica actual
- Tus objetivos profesionales

#### 🎨 intereses.md
Incluye:
- Hobbies y pasatiempos
- Deportes que practicas
- Música que escuchas
- Libros o películas favoritas
- Tecnologías que te interesan

#### 💼 proyectos.md
Describe:
- Proyectos académicos en los que estás trabajando
- Ideas de proyectos futuros
- Habilidades que quieres desarrollar
- Cursos o certificaciones que planeas obtener

#### 📞 contacto.md
Proporciona:
- Email académico/profesional
- Perfil de LinkedIn (si tienes)
- Otras redes sociales profesionales
- Forma preferida de contacto

## 💡 Ejemplo de Estructura para README.md

```markdown
# [Tu Nombre]

![Tu Foto](ruta/a/tu/foto.jpg) *(opcional)*

## Sobre Mí

¡Hola! Soy [tu nombre], estudiante de [tu curso/carrera] en [tu institución]. 
Me apasiona [menciona tus áreas de interés] y estoy emocionado/a de 
aprender más sobre programación y desarrollo de software.

Actualmente estoy enfocado/a en [menciona tu área de estudio actual] 
y mi objetivo es [describe tus metas profesionales].

## Formación Académica

- **[Año - Presente]**: [Nombre del curso/carrera] - [Institución]
- **[Años anteriores]**: [Formación previa relevante]

## Objetivos Profesionales

- [Objetivo 1]
- [Objetivo 2]
- [Objetivo 3]

## Enlaces Rápidos

- 🎨 [Mis Intereses](intereses.md)
- 💼 [Mis Proyectos](proyectos.md)
- 📞 [Contacto](contacto.md)
```

## ✅ Criterios de Evaluación

| Criterio | Puntos | Descripción |

| **Archivos adicionales** | 25 | Los archivos intereses.md, proyectos.md y contacto.md están presentes y completos |

| **Presentación profesional** | 10 | El contenido es apropiado, bien redactado y profesional |
