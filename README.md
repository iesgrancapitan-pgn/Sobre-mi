# Sobre mí

## Objetivo
Aprender los formatos básicos de Markdown (títulos, listas, imágenes, enlaces, negrita, cursiva, etc.) modificando un fichero de presentación personal.

---

## Instrucciones

1. Descarga el archivo `presentacion.md` de tu repositorio en GitHub Classroom.
2. Modifica el archivo siguiendo el ejemplo y las indicaciones de abajo.
3. Cuando termines, sube los cambios a tu repositorio.

---

## Ejemplo de estructura y formatos a practicar

# Presentación personal

---

## Formatos que debes usar
- Títulos y subtítulos (`#`, `##`)
- Listas simples y anidadas (`-`, `  -`)
- Imágenes (`![Texto alternativo](URL)`)
- Enlaces (`[Texto](URL)`)
- Negrita (`**texto**`)
- Cursiva (`*texto*`)
- Citas (`> texto`)

---

## Recomendaciones
- Personaliza el contenido con tus datos reales.
- Usa una foto tuya (puedes subirla al repositorio y enlazarla).
- Sé creativo y cuida la presentación.
