# 📝 Guía Rápida de Markdown para Estudiantes

## ¿Qué es Markdown?
Markdown es un lenguaje de marcado ligero que te permite formatear texto de manera sencilla. Es muy popular en GitHub, blogs técnicos y documentación.

## 🔤 Sintaxis Básica

### Encabezados
```markdown
# Encabezado 1 (Título principal)
## Encabezado 2 (Subtítulo)
### Encabezado 3 (Sub-subtítulo)
#### Encabezado 4
##### Encabezado 5
###### Encabezado 6
```

### Texto con Formato
```markdown
**Texto en negrita**
*Texto en cursiva*
***Texto en negrita y cursiva***
~~Texto tachado~~
`Código en línea`
```

**Resultado:**
- **Texto en negrita**
- *Texto en cursiva*
- ***Texto en negrita y cursiva***
- ~~Texto tachado~~
- `Código en línea`

### Listas

#### Lista con viñetas:
```markdown
- Elemento 1
- Elemento 2
  - Sub-elemento 2.1
  - Sub-elemento 2.2
- Elemento 3
```

#### Lista numerada:
```markdown
1. Primer elemento
2. Segundo elemento
3. Tercer elemento
```

#### Lista de tareas:
```markdown
- [x] Tarea completada
- [ ] Tarea pendiente
- [ ] Otra tarea pendiente
```

### Enlaces e Imágenes

#### Enlaces:
```markdown
[Texto del enlace](https://ejemplo.com)
[Enlace con título](https://ejemplo.com "Título del enlace")
```

#### Imágenes:
```markdown
![Texto alternativo](ruta/a/la/imagen.jpg)
![Texto alternativo](https://ejemplo.com/imagen.jpg "Título de la imagen")
```

### Código

#### Bloque de código:
```markdown
```python
def hola_mundo():
    print("¡Hola, mundo!")
```
```

#### Código en línea:
```markdown
Usa la función `print()` para mostrar texto.
```

### Citas
```markdown
> Esta es una cita.
> Puede ocupar múltiples líneas.
>
> Y tener párrafos separados.
```

### Líneas Horizontales
```markdown
---
***
___
```

### Tablas
```markdown
| Columna 1 | Columna 2 | Columna 3 |
|-----------|-----------|-----------|
| Fila 1    | Dato      | Dato      |
| Fila 2    | Dato      | Dato      |
```

## 🎨 Elementos Avanzados

### Emojis
Puedes usar emojis directamente o con códigos:
```markdown
🚀 ⭐ 💻 📚
:rocket: :star: :computer: :books:
```

### Alertas y Callouts
```markdown
> **Nota:** Esto es información importante.

> **⚠️ Advertencia:** Ten cuidado con esto.

> **💡 Consejo:** Aquí tienes un truco útil.
```

### Escapar Caracteres
Si necesitas mostrar caracteres especiales de Markdown:
```markdown
\* No será cursiva \*
\# No será un encabezado
```

## ✅ Lista de Verificación para tu Proyecto

### Estructura Básica
- [ ] README.md creado y completo
- [ ] intereses.md creado
- [ ] proyectos.md creado  
- [ ] contacto.md creado

### Formato y Estilo
- [ ] Uso correcto de encabezados (# ## ###)
- [ ] Listas bien formateadas
- [ ] Enlaces funcionando correctamente
- [ ] Uso apropiado de énfasis (**negrita**, *cursiva*)
- [ ] Código formateado correctamente (si aplica)

### Contenido
- [ ] Información personal completa pero apropiada
- [ ] Descripción clara y profesional
- [ ] Objetivos bien definidos
- [ ] Intereses detallados y auténticos
- [ ] Proyectos descritos claramente
- [ ] Información de contacto profesional

### Calidad
- [ ] Ortografía y gramática correctas
- [ ] Tono profesional pero accesible
- [ ] Información actualizada
- [ ] Enlaces funcionando
- [ ] Imágenes cargando correctamente (si las hay)

## 🐛 Errores Comunes a Evitar

1. **Espacios después de #**: Siempre usa `# Título` no `#Título`
2. **Listas mal formateadas**: Asegúrate de tener espacios después de `-` o números
3. **Enlaces rotos**: Verifica que todas las URLs funcionen
4. **Falta de líneas en blanco**: Deja líneas vacías entre secciones
5. **Información demasiado personal**: Mantén un equilibrio entre personal y profesional

## 🎯 Consejos para Destacar

1. **Usa emojis moderadamente** para hacer tu perfil más visual
2. **Estructura clara** con encabezados bien organizados
3. **Sé auténtico** pero profesional
4. **Actualiza regularmente** tu información
5. **Añade enlaces** a tus trabajos cuando sea posible
6. **Usa listas de tareas** para mostrar progreso y objetivos
